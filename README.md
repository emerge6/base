Base Package Manager

Base — это легкий и эффективный менеджер пакетов для управления зависимостями и сборкой программ.

    infuse <package> — Установить пакет и его зависимости.

    rip <package> — Удалить указанный пакет.

    pulse — Очистить и синхронизировать кэш.

    list — Показать список установленных пакетов.

    hunt <query> — Найти пакеты по запросу.

    lore <package> — Показать информацию о пакете.

    clean — Очистить старые версии пакетов.

    web <package> — Показать граф зависимостей.

Пример использования

base infuse fastfetch
base rip fastfetch
base pulse
base list
